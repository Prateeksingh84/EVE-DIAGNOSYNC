System Architecture & Production Specifications

Design decisions implemented for EVE Healthcare SDE Assignment

Dual DB Engine & Universal UUID

Implemented universal SQLAlchemy 2.0 Uuid type with automatic runtime fallback from PostgreSQL to aiosqlite for zero-config local development.

Idempotent Webhook Processing

Every webhook event ID is recorded in webhook_events. Repeated webhook calls return already_processed safely.

Fast Cache Circuit Breaker

Circuit-breaker pattern in cache_service.py: if Redis is offline, it bypasses immediately (<5ms) rather than waiting 5 seconds on timeouts.
