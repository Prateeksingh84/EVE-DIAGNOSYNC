Layered Clean Architecture

The service is structured following Domain-Driven principles, separating the HTTP transport layer from business logic and database persistence.

1. API Routers

FastAPI routers handle serialization, query parameters, JWT authentication, and HTTP status codes.

2. Service Layer

Pure business logic, booking state machine transitions, simulated payment algorithms, and idempotency checks.

3. Schemas (Pydantic v2)

Strict request validation (password strength, future appointment dates, valid phone numbers).

4. ORM & Persistence

SQLAlchemy 2.0 with universal UUIDs, junction tables with per-centre test pricing, and migrations.
